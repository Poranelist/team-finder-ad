# TeamFinder — платформа для поиска команды над pet-проектами

TeamFinder — это онлайн-платформа для поиска соавторов и единомышленников среди IT-специалистов. Здесь можно публиковать свои идеи, собирать команду для pet-проектов и откликаться на предложения других участников.

## Функциональность

- **Регистрация и аутентификация** по email и паролю.
- **Управление профилем** – аватар, контакты, навыки (телефон, GitHub, описание).
- **Проекты** – создание, редактирование, завершение. Каждый проект имеет автора, описание, статус (открыт/закрыт), список участников.
- **Избранное** – авторизованные пользователи могут добавлять проекты в избранное и просматривать отдельную страницу избранного.
- **Участие в проектах** – пользователь может присоединиться к чужому проекту или отказаться от участия.
- **Фильтрация пользователей** на странице участников по четырём критериям:
  - Авторы избранных проектов
  - Авторы проектов, в которых я участвую
  - Пользователи, которым нравятся мои проекты
  - Участники моих проектов
- **Пагинация** – на главной странице (12 проектов) и на странице пользователей (12 профилей).
- **Генерация аватара** по умолчанию – первая буква имени на пастельном фоне.
- **Админ-панель** для управления пользователями и проектами.

## Стек технологий

- **Backend:** Django 5.2, Python 3.13.12
- **База данных:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript

## Развёртывание проекта

### Требования

- Python 3.10+
- Docker
- Git

### Клонирование репозитория

```bash
git clone <https://github.com/Poranelist/team-finder-ad.git>
cd team-finder-ad
```

### Виртуального окружение

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Переменные окружения

Скопируйте пример файла и отредактируйте:

```bash
cp .env_example .env
```

Откройте `.env` и укажите свои значения:

| Переменная               | Описание                                                                 | Пример                       |
|--------------------------|--------------------------------------------------------------------------|------------------------------|
| DJANGO_SECRET_KEY        | Секретный ключ Django                                                    | `+6*w_6+0y$_...`            |
| DJANGO_DEBUG             | Режим отладки. `True` для разработки, `False` для продакшена             | `True`                       |
| DJANGO_ALLOWED_HOSTS     | Домены/IP через запятую (для разработки можно `*`)                       | `localhost,127.0.0.1`        |
| POSTGRES_DB              | Имя базы данных PostgreSQL                                               | `teamfinder`                 |
| POSTGRES_USER            | Пользователь PostgreSQL                                                  | `postgres`                   |
| POSTGRES_PASSWORD        | Пароль                                                                   | `strongpassword`             |
| POSTGRES_HOST            | Хост БД (при локальном запуске – `localhost`, при Docker – `db`)         | `localhost`                  |
| POSTGRES_PORT            | Порт БД (по умолчанию `5432`)                                            | `5432`                       |
| TASK_VERSION             | Номер варианта (всегда `1` для данного проекта)                          | `1`                          |

### Генерация DJANGO_SECRET_KEY:
```
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

### Docker

Запустите контейнеры:

```bash
docker compose up --build
```

Остановить контейнеры:

```bash
docker compose down
```

порт `5432`.

### Применение миграций

```bash
python manage.py migrate
```

### Создание суперпользователя

```bash
python manage.py createsuperuser
```

### Запуск сервера разработки

```bash
python manage.py runserver
```

После этого приложение будет доступно по адресу [http://localhost:8000](http://localhost:8000).  
Админ-панель: [http://localhost:8000/admin](http://localhost:8000/admin)
